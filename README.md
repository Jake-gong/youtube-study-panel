# YouTube Study Panel

独立的 Chrome / Edge Manifest V3 扩展，为 YouTube 增加英语学习字幕面板。

## 当前功能

- 播放器左下角 `Study` 开关
- 右侧可折叠字幕面板
- 当前字幕高亮并自动跟随
- 点击字幕跳转并播放对应位置
- 双击字幕或点击循环按钮进行单句循环
- `0.25×–2.00×` 播放速度调节，步长为 `0.05`
- 可选择是否记住播放速度
- 下载当前字幕为 `SRT`、`VTT` 或 `TXT`
- 字幕数据只在浏览器本地处理

## 安装

1. 打开 `chrome://extensions` 或 `edge://extensions`
2. 开启“开发者模式”
3. 点击“加载已解压的扩展程序”
4. 选择本项目文件夹
5. 打开或刷新一个带字幕的 YouTube 视频

## 使用

- 点击播放器控制栏中的 `Study` 打开学习面板。
- 点击任意字幕可跳转并播放。
- 双击字幕，或点击字幕右侧的循环按钮，可重复播放该句。
- 手动滚动字幕后会暂停自动跟随；点击“跟随当前”即可恢复。
- 使用面板中的 `−`、`+` 按钮以 `0.05` 为步长调速，点击速度数字恢复 `1.00×`。

## 已知限制

- 依赖 YouTube 当前页面提供的字幕轨道；YouTube 改版后可能需要维护。
- 无字幕、受限字幕和部分直播字幕无法读取。
- 第一版不包含翻译、单词查询和云同步。

## 更新记录

- `0.1.7`：点击字幕进入句首预听区间时短暂锁定目标句高亮，播放到真实句首后再交还自动跟随，消除绿色背景跳回上一句的闪动。
- `0.1.6`：优先使用 JSON3、VTT 和 XML/SRV3 中的词级时间戳计算完整句子的起止位置，并在点击字幕时加入极短预听余量，提升跳转和单句循环的对齐准确度。
- `0.1.5`：侧边栏字幕改为按完整句子显示；跨越多个 YouTube 时间片的句子会自动合并，同时保留点击跳转、当前句跟随、单句循环和下载时间轴。
- `0.1.4`：截获到的字幕正文按实际格式自动识别（JSON3 / VTT / XML），修复 VTT 正文被当成 XML 解析导致的“Invalid caption XML”；截获等待与重放更宽松（多候选地址依次尝试）。
- `0.1.3`：直接截获 YouTube 播放器通过 `fetch` 或 `XMLHttpRequest` 获取的字幕正文，避免对带 PO Token 的字幕地址进行无效的二次请求。
- `0.1.2`：复用 YouTube 播放器生成的字幕 PO Token 请求，修复 `timedtext` 返回 HTTP 200 空正文的问题。
- `0.1.1`：字幕文件改由 YouTube 页面环境请求，避免内容脚本隔离导致读取失败；错误提示会显示超时或 HTTP 状态。
- `0.1.0`：首个可用版本。
