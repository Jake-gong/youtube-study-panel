# YouTube Study Panel

独立的 Chrome / Edge Manifest V3 扩展，为 YouTube 增加英语学习字幕面板。

> 面向使用者的功能说明见本文件；项目架构、设计决策、测试与发布流程见 [PROJECT.md](./PROJECT.md)。

## 当前功能

- 播放器左下角 `Study` 开关
- 右侧可折叠字幕面板
- **视频内嵌字幕**：保持原版字号，每页最多两行，长字幕按实际宽度分页接续；有对应词级时间时使用原生时间，没有时按段内文本位置近似分配。侧栏、查词和收藏保留完整字幕段。
- 当前字幕高亮并自动跟随
- 点击字幕时间戳播放对应位置，点击英文单词查义
- 点击 ↻ 循环当前段，双击字幕行空白处也可循环
- 设置 A/B 时间点，循环播放任意视频片段
- 在进度条上显示并拖动 A/B 标记进行微调
- 使用 `Shift+A`、`Shift+B`、`Shift+L`、`Shift+X` 快捷操作 A-B 循环
- 按视频在浏览器本地记忆 A/B 时间点和循环状态
- `0.25×–2.00×` 播放速度调节，步长为 `0.05`
- 可选择是否记住播放速度
- 逐句自动暂停，配合精听
- 字幕隐藏/模糊模式，悬停显示，练听力
- 点击字幕中的单词查英文释义（dictionaryapi.dev）
- 收藏生词和例句，一键回到原字幕段时间点
- 生词本导出 CSV / Anki
- 单键句子导航 `A`/`S`/`D`，`W` 播放暂停，`R` 收藏当前段，`Shift+C` 复制当前段（Markdown 带时间戳链接）
- 下载当前字幕为 `SRT`、`VTT` 或 `TXT`
- 字幕数据只在浏览器本地处理（词典查词除外，见隐私说明）

## 下载与安装

1. 打开 [最新版本下载页面](https://github.com/Jake-gong/youtube-study-panel/releases/latest)
2. 下载 `youtube-study-panel-v1.0.8.zip` 并解压
3. 打开 `chrome://extensions` 或 `edge://extensions`
4. 开启“开发者模式”
5. 点击“加载已解压的扩展程序”
6. 选择解压后的 `youtube-study-panel` 文件夹
7. 打开或刷新一个带字幕的 YouTube 视频

## 使用

- 下载与复制位于“更多”；“记住速度”位于设置。
- 设置页的查词方式、速度记忆和 AI 参数修改后统一点击“保存设置”。“测试连接”仅验证草稿，不修改已保存配置。切换服务商会清空 Key，请重新填写。
- AI 请求 10 秒超时，关闭查询或切换视频会取消对应 AI 请求；请求未完成时相同查询合并。自定义接口仅接受 HTTPS。
- 文中的“段”指侧栏字幕段，通常为约 12 词以内的自动字幕短语；人工字幕可能较长。视频分页不改变侧栏或收藏的段落上下文。

- 点击播放器控制栏中的 `Study` 打开学习面板。
- 点击字幕时间戳播放该段，点击英文单词查义。
- 点击字幕右侧 ↻ 循环该段；双击行空白处也可循环，双击单词不会触发循环。
- 点击播放器控制栏中的 `A`、`B` 记录片段起止点；两个点有效时会自动开始循环。
- 点击 `AB` 开关可暂停或恢复片段循环；点击单个 `×` 删除对应时间点，点击“清除”删除全部时间点。
- 拖动进度条上的橙色 A 标记或蓝色 B 标记，可微调循环范围。拖动期间视频会暂停，结束后恢复原播放状态。
- 快捷键：`Shift+A` 设置 A 点，`Shift+B` 设置 B 点，`Shift+L` 开关循环，`Shift+X` 清除时间点。输入文字时快捷键不会触发。
- 单句循环与 A-B 片段循环互斥；启用其中一种会停止另一种，避免播放位置冲突。单句循环或 A-B 循环激活期间，逐句自动暂停暂时不生效。
- 手动滚动字幕后会暂停自动跟随；点击“跟随当前”即可恢复。
- 使用面板中的 `−`、`+` 按钮以 `0.05` 为步长调速，点击速度数字恢复 `1.00×`。
- 点击“自动暂停”或按 `Q`：每段播完、进入下一句时自动暂停，方便逐句精听；按 `W` 或空格继续。
- 点击“隐藏字幕”或按 `E`：字幕文本变模糊，悬停某句可临时显示，点击照常跳转播放。
- 点击字幕中的英文单词：**自动暂停**并弹出详细词典卡片——顶部显示原字幕段并把所点单词高亮，词义按与当前段子的重合度排序（最可能的义项标注“结合上下文”），显示音标、多个词性和释义、例句；点击“收藏这个单词”连例句一起保存。侧边栏字幕和视频内嵌字幕里的单词都可以点击，再次点击同一单词关闭卡片。
- **可选 AI 词典**：在面板“⚙ 设置”里填入自己的大模型 API Key（支持智谱 GLM / DeepSeek / Kimi / OpenAI / 通义千问 / 任意 OpenAI 兼容接口），悬停直接出**中文简明释义**、点击出**结合原字幕段的中文讲解**（在本段中的含义、其他含义、例句），查询结果本地缓存、相同模型与上下文命中缓存时不再请求；AI 失败自动回退免费词典。适合分享给他人使用——每人用自己的 Key，无需打包任何词典数据。
- **可选本地词典（离线秒查）**：在设置里点“下载本地词典”（约 2.2MB，3 万高频词英汉，含音标），安装后悬停/点击**零网络请求、毫秒级**出中文释义；数据保存在本机，可随时删除。适合网络不佳或不想调用任何在线服务的场景。
- **悬停**字幕中的英文单词（约 0.15 秒）：卡片先立即出现并显示"查询中…"，释义到达后原地填充，不会暂停播放，移开即消失。已查过的词会本地缓存（跨页面、跨会话生效），再次悬停瞬间显示；查询并发尝试词形变化（如 running → run）并在网络不佳时最多等待 5 秒后快速提示。
- 点击“视频字幕”开关：在视频画面下方叠加当前段的绿色字幕，点击其中单词即可查义，悬停可显示 ↻ 重播本段和 ☆ 收藏本段按钮；再次点击同一点单词关闭弹窗。开启时 YouTube 原生 CC 会被隐藏（避免重复显示），关闭开关或关闭 Study 面板即恢复并隐藏视频字幕。视频字幕默认开启；它依赖 Study 面板读取过的字幕数据，换视频后需打开面板加载一次。配合“隐藏字幕”模式，视频字幕同样会模糊显示。
- 收藏句子：右键点击任意字幕句、悬停句子点 `☆`，或按 `R` 收藏当前段。
- 点击“生词本”查看全部收藏：条目可点击回到原视频时间点，可单独删除；支持导出 CSV（Excel）和 Anki（TSV，含来源链接）。
- 按 `Shift+C` 或在“更多”中点击“复制本段”：以 Markdown 复制当前段和带时间戳的视频链接，方便贴进笔记。
- 面板打开时支持单键操作：`A` 上一句、`S` 重播当前段、`D` 下一句、`W` 播放/暂停、`Q` 自动暂停开关、`E` 隐藏字幕开关、`R` 收藏当前段。输入文字时不会触发。
- 面板顶部“字幕”下拉框切换字幕语言：**只有手动选择才会被记住**；没有记忆时自动优先选择人工英语字幕，其次是自动生成英语字幕，再次是其他人工字幕，避免意外锁定到非英语轨道。

## AI 词典配置（可选）

1. 打开 Study 面板，点击工具行“⚙ 设置”。
2. 查词方式选“AI 大模型（需 API Key）”。
3. 选择服务商，预设会自动填好接口地址和推荐模型：
   - **智谱 GLM**：`open.bigmodel.cn` 注册，`glm-4-flash` 目前免费，适合入门
   - **DeepSeek**：`platform.deepseek.com`，`deepseek-chat`，价格极低
   - **Kimi（月之暗面）**：`platform.moonshot.cn`，`moonshot-v1-8k`
   - **OpenAI**：`gpt-4o-mini`
   - **通义千问**：阿里云百炼，`qwen-turbo`
   - **自定义**：任何 OpenAI 兼容接口，填 Base URL（一般以 `/v1` 结尾）和模型名
4. 粘贴 API Key，点“测试连接”确认可用，然后“保存设置”。
5. 之后悬停单词 = AI 中文简明释义（卡片带 AI 标记），点击单词 = AI 结合原字幕段的三段式讲解（在本段中 / 其他含义 / 例句），释义自动缓存，第二次起瞬间显示。

说明：API Key 只保存在你自己浏览器的 `chrome.storage.local`，不会发给除所选服务商之外的任何一方；使用自定义接口时该地址需允许浏览器跨域请求（CORS）。

## 本地词典（可选，离线秒查）

1. 打开 Study 面板 → “⚙ 设置” → 查词方式选“**本地词典（离线秒查）**”。
2. 点击“**下载本地词典（约 2.2MB）**”，安装 3 万高频词的英汉词典（数据来自开源词库 [ECDICT](https://github.com/skywind3000/ECDICT)，MIT 协议）。下载来源优先级：
   - 插件包内的 `dict/zh-gloss.json`（如果打包时包含了这个文件，安装完全离线、瞬间完成）；
   - 否则从 GitHub 仓库下载 `dict/zh-gloss.json`（需要仓库已推送该文件）。
3. 网络不便时，也可以手动下载 `dict/zh-gloss.json`，点“**从文件导入**”安装。
4. 安装后：悬停单词 → 本地中文简明释义（带音标和“本地”标记），点击 → 原字幕段上下文 + 完整中文释义，**全部零网络请求**；本地词典未收录的词自动回退在线词典。
5. 可随时点“删除”卸载；删除后查词方式自动切回免费词典。

重新生成词典文件：`node scripts/build-local-dict.cjs <ecdict.csv 路径> [词数]`（源数据从 ECDICT 仓库下载）。

## 已知限制

- 依赖 YouTube 当前页面提供的字幕轨道；YouTube 改版后可能需要维护。
- 无字幕、受限字幕和部分直播字幕无法读取。
- 词典查询只支持英文单词（dictionaryapi.dev），查询时会把所点的单词发送给该服务；其余功能全部本地运行。
- 第一版不包含翻译和云同步。

## 开发验证

运行 `node .test/ab-loop-smoke.js`、`node .test/caption-bridge-smoke.js`、`node .test/study-tools-smoke.js` 和 `node .test/phrase-edge-cases.cjs`，可检查循环播放、字幕点击、过期字幕地址自动刷新、学习工具、以及短语聚合的边界情形（说话人标记、缩写、撇号分词、12 词切断、零时长兜底）。

## 隐私

字幕只在浏览器本地处理，不会上传到第三方服务器。点词查义时，所点的单词会发送给免费的 dictionaryapi.dev 词典服务；生词本数据只保存在本地。详情见 [PRIVACY.md](./PRIVACY.md)。

## 更新记录

- `1.0.8`：修复打开 Study 面板卡顿数秒——分页测量对每个短语的每个词前缀都做真实 DOM 强制重排（长视频上万次）；现改为整段一次测量的快速通道（两行内直接单页），测量次数降约 15 倍，超长行才走逐词分页。
- `1.0.7`：修复悬停简明释义不再出现（只剩点击详解）——短语切换（约每 3 秒）曾无条件关闭悬停提示，150ms 防抖窗口撞上即永不出现；侧边栏“跟随当前”的平滑滚动也会关闭提示。现改为锚点存活检测：悬停的词仍在页面上时提示保留（滚动时重新定位跟随），词被新短语替换才关闭。
- `1.0.6`：修复字幕切换滞后（人已说到下一句、屏幕仍显示上一句）——YouTube 的 `dDurationMs` 是"显示停留时长"，比实际语音长，导致相邻短语时间区间重叠；重叠区内二分查找固定返回较早的短语。现在在词级（normalizeCues）与短语块级（buildOverlayChunks）两处把结束时间钳制到后继开始，保证时间轴单调：下一短语从其开始时刻立即接管显示。副作用修复：短语间真实停顿（>0.6s）不再被拖长的结束时间掩盖，停顿切分更准。
- `1.0.5`：视频字幕按真实两行布局分页，保留原字号并响应宽度与字体变化；修复设置测试竞争、按钮键盘操作、双击单词误循环；新增 AI 超时/取消/去重与按模型缓存；设置统一保存，工具栏精简。

以下为历史版本记录，旧版的单行、缩字号及完整句描述不代表当前行为。


- `1.0.4`：改善视频字幕与音频的同步——短语切换检测从 `timeupdate` 事件（约 250ms 一次，边界平均迟到 125ms）改为播放期间 `requestAnimationFrame` 逐帧检测（约 16ms 精度），拖动进度条即时刷新，暂停/关闭面板自动停止检测。注：YouTube 自动字幕的词级时间戳本身存在 ±0.2~0.5 秒识别漂移（Language Reactor 同样存在），该部分为上游数据特性。
- `1.0.3`：修复“跟随当前”点击后当前句被顶部功能区遮挡的问题——滚动定位原先用 `offsetTop`（相对面板定位上下文，偏差约等于头部+工具栏+工具行高度，导致滚动过头），改为 `getBoundingClientRect` 差值计算，与布局结构无关，当前句精确滚动到列表可视区中央。
- `1.0.2`：自查修复短语聚合的两个边界 bug——撇号分词拼接（don + 't 曾被错误拼成 "don 't"）；单词缩写（Mr. 等）曾被单独切成短语。新增 `phrase-edge-cases.cjs` 边界测试（说话人标记 `>>`、换行分段、缩写、撇号、12 词切断、零时长词兜底），并清理死代码。
- `1.0.1`：修正 v1.0.0 对分段粒度的错误假设——YouTube 自动字幕（json3）的"原生分段"实际是**词级事件**（一个事件一个词），直接使用导致视频字幕一词一闪。现按 Language Reactor 的方式把词级事件**聚合成短语**（约 5~12 词，句末标点/停顿>0.6 秒/满 12 词时切断；人工字幕整行保留），侧边栏字幕稿与视频字幕均以短语为单位、时间精确接续；超长整行分段字号自适应缩小不变。
- `1.0.0`：视频字幕架构对齐 Language Reactor——**显示单元改为 YouTube 原生字幕分段**（不再把分段合并成句后再切块），时间精确、单行大字号、与语音天然同步；个别超长分段字号按容量自适应缩小（下限 65%）；句子合并仅保留给侧边栏字幕稿与查词/AI/收藏的完整句上下文。自此"长句截断/丢词"一类问题在架构上不再存在。
- `0.9.3`：视频字幕改为**单行显示**——短语块上限从"两行容量"改为"一行的实测容量"（探针按当前字号与播放器宽度实测，宽屏约 12~18 词，测量失败回退 15 词），CSS 同步限一行；块仍按标点/连词自然断点切分、按时间轴接续。
- `0.9.2`：找到字幕框一直只有播放器约一半宽的根本原因——绝对定位 `left:50%` + 位移居中的写法把元素可用宽度限制在了父容器的一半（`max-width: 94%` 形同虚设），历史上多轮“块太长”问题均由此放大。改为 `left:3%; right:3%` 真实占满 94% 宽度（文字仍居中），字幕文本区 `flex:1` 撑满；容量探针宽度公式同步修正（94% 宽 − 操作列 − 内边距），切块长度与实际渲染终于一致。
